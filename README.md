# 專利元件符號輸入工具 (ComponentsIME) v2.0.0

**專利元件符號輸入工具** 是一款基於 [AutoHotkey v2](https://www.autohotkey.com/) 開發的輔助輸入工具，旨在提升專利說明書撰寫與審查過程中輸入「元件名稱」與「元件符號編號」的效率。

---

## 🌟 主要功能特點

1. **熱字串（Hotstring）快速替換**
   - 輸入 `元件編號/`（例如 `100/`），即可自動替換並輸出對應的 `元件名稱 + 編號`（例如 `Hobot擦窗機100`）。

---

## 🌟 其他功能   
2. **前置視窗自動追蹤與輸入**
   - 使用 Windows API (`SetWinEventHook`) 自動紀錄上一個作用中的視窗（如 Word、文字編輯器等）。
   - 在本工具列表中點選元件時，會自動切換回上一個視窗並插入選取的元件符號。
3. **動態元件配對管理**
   - 支持在 GUI 介面中新增、編輯、刪除元件配對。
   - **剪貼簿快速新增**：選取文字後按下快捷鍵，自動解析元件名稱與編號並加入選單。
4. **安全備份機制**
   - 每次修改元件資料庫（`components.txt`）時，會自動在 `backup/` 目錄建立帶時間戳記的備份檔。
5. **動態廣告與贊助公告**
   - 每 30 分鐘自動更新背景廣告與公告訊息。
   - 提供「贊助」功能快速開啟推廣頁面。
6. **整合外部工具**
   - 選單提供快速開啟 `components.txt` 資料檔及元符產生器腳本功能。

---

## 🛠️ 系統需求

- **作業系統**：Windows 10 / 11
- **執行環境**：[AutoHotkey v2.0+](https://www.autohotkey.com/v2/)

---

## 📁 檔案結構

```text
ComponentsIME/
├── ComponentsIMEv02.ahk     # AHK v2 主程式腳本
├── components.txt            # 元件配對資料庫 (格式：編號：元件名稱)
├── ComponentsIME-ad.html     # 下載與展示之廣告頁面
├── ComponentsIMEv02.ico      # 程式圖示
├── README.md                 # 專利元件符號輸入工具說明文件
└── backup/                   # components.txt 自動備份資料夾
```

---

## ⌨️ 快捷鍵與操作說明

| 快捷鍵 | 功能說明 |
| :--- | :--- |
| `編號/` | **熱字串替換**（例如輸入 `100/` 自動輸出 `Hobot擦窗機100`） |
| `Ctrl + N` | 開啟 **「新增元件配對」** 對話盒 |
| `Shift + 上鍵` (`Shift+Up`) | 複製目前選取的文字，自動解析名稱與編號並加入元件列表 |
| `Ctrl + Q` | 退出程式 |

---

## 📄 資料檔格式 (`components.txt`)

`components.txt` 使用全形或半形冒號做為分隔符，格式如下：

```text
100：Hobot擦窗機
102：驅動馬達
200：控制模組
```

---

## 🚀 使用方法

1. 安裝 [AutoHotkey v2](https://www.autohotkey.com/)。
2. 雙擊執行 `ComponentsIMEv02.ahk`。
3. 程式啟動後會置於螢幕右側，並監聽鍵盤輸入。
4. 在任何編輯器中輸入 `編號/` 即可進行快速插入。
